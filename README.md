# 共演战略画布 · Co-Evolution Strategy Canvas

> 一个为 EMBA 课堂设计的交互式战略学习与推演工具：把路江涌教授的「共演战略」从一本书，变成一张可以动手的画布。

**理论基石**：路江涌《共演战略：重新定义企业生命周期》（2018）、《共演战略画布》（2019，机械工业出版社）

**在线体验**：`https://<your-name>.github.io/co-evolution-canvas/`（发布后替换）

---

## 这是什么

大多数战略工具在教「知识点」，这个工具在练「判断力」。

共演战略把企业战略拆成两条线：

- **空间**：用户、组织、产品、市场四个要素，构成「内与外 × 人与事」的 2×2 矩阵；
- **时间**：精益创业、专益成长、增益扩张、升益转型四个阶段，沿企业生命周期演进。

两者交叉，得到 **48 个战略演化**（12 个战略要点 × 4 个阶段）。本工具把这套框架做成三种可交互的形态：

| 场景 | 做什么 | 产出 |
| --- | --- | --- |
| **课前**（约 20 分钟） | 读理论图谱、做阶段自评、为 12 个要点打分 | 一份「课前诊断卡」 |
| **课中**（约 90 分钟） | 案例沉浸：在真实抉择里做选择、看结果、找要素失衡 | 一张「共演失衡图」 |
| **课后**（约 30 分钟） | 生成一页纸备忘录、写 30 天行动、月度复盘 | 战略备忘录 + 行动清单 |

## 核心功能

### 1. 可交互战略画布

- 四象限对应四要素，每个象限下是 3 个战略要点，共 12 项 1–5 分评分；
- 切换阶段时，同一要点的名称随之变化（例如「用户特征」在四阶段依次是：天使用户 → 大众用户 → 累积用户 → 重识用户）；
- 实时诊断：要素雷达、完成度、失衡提示、阶段匹配度、优先动作建议；
- 评分与备注自动保存在浏览器本地，可随时导出 / 导入 JSON。

### 2. 沉浸式案例库

10 个真实中国企业案例（小米、美团、字节跳动、拼多多、蔚来、比亚迪、华为、海尔、三顿半、宁德时代）+ 4 个反例：

- 阶段旅程时间轴、四要素关键动作、可核实的关键数字；
- **关键抉择模拟**：停在一个「当时没有标准答案」的决策点，先选，再看历史选择与共演解读；
- 案例—阶段教学矩阵，支持按阶段 / 行业筛选与关键词搜索。

### 3. 理论图谱

四要素 / 四阶段 / 48 演化总表 / 双 S 曲线四个模块：

- 2×2 矩阵与 12 要点详情，含「常见误读」；
- 48 演化矩阵支持按阶段高亮，横向看演化、纵向看组合；
- 双 S 曲线（A 曲线 / B 曲线 / C 曲线）与「四益法则」（减法 / 乘法 / 加法 / 除法）。

### 4. 战略测评

15 道情境判断题，即时解析，按四要素拆解得分，输出画像与错题复盘，可下载报告。

### 5. 我的工作台

一页纸战略备忘录、30 天行动清单（可勾选完成）、课前 / 课中 / 课后使用指引、Markdown / JSON 导出、打印。

## 适配与体验

- **响应式**：桌面（2 列画布 + 侧栏诊断）、平板、手机（四象限切换 + 单列布局）三档验证；
- **深色模式**：跟随系统或手动切换，所有图表同步换色；
- **无障碍**：语义化标签、键盘评分（聚焦要点后按 1–5）、跳过导航链接、`aria-*` 状态、减少动效支持；
- **零依赖**：无框架、无构建、无追踪脚本、无外部字体或 CDN，全部图表手写 SVG；
- **数据本地**：所有内容保存在 `localStorage`，不上传服务器。

## 本地运行

```bash
# 任选其一
node server.js            # 内置零依赖静态服务器 → http://127.0.0.1:4173
python -m http.server 4173
npx serve .
```

> 直接双击 `index.html` 也可以打开（使用 Hash 路由），但建议用本地服务器以获得完整行为。

## 项目结构

```
co-evolution-canvas/
├── index.html              # 单页入口
├── 404.html                # GitHub Pages 404
├── server.js               # 本地预览服务器（零依赖）
├── css/
│   ├── tokens.css          # 设计变量（颜色 / 字体 / 间距 / 深浅色）
│   ├── base.css            # Reset、排版、布局、页头页脚
│   ├── components.css      # 按钮、卡片、表单、弹层、提示
│   └── views.css           # 各页面与图表样式
├── js/
│   ├── app.js              # 入口：主题、路由注册、全局交互
│   ├── router.js           # 极简 Hash 路由
│   ├── store.js            # 状态、持久化、诊断引擎
│   ├── charts.js           # 双 S 曲线 / 雷达 / 进度环 / 矩阵（手写 SVG）
│   ├── util.js             # DOM 助手、存储、Toast、弹层、导出
│   ├── data/
│   │   ├── theory.js       # 四要素、四阶段、48 演化、四问、四益
│   │   ├── cases.js        # 10 个案例 + 4 个反例
│   │   └── quiz.js         # 15 道情境题与画像
│   └── views/              # 首页 / 理论 / 画布 / 案例 / 测评 / 工作台 / 关于
└── .tools/                 # 开发期 QA 脚本（不参与站点运行）
```

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "feat: 共演战略画布 v1.0"
git branch -M main
git remote add origin https://github.com/<your-name>/co-evolution-canvas.git
git push -u origin main

# 开启 Pages（main 分支根目录）
gh api -X POST repos/<your-name>/co-evolution-canvas/pages \
  -f source[branch]=main -f source[path]=/
```

站点为纯静态 Hash 路由应用，无需任何构建或额外配置；仓库根目录已包含 `.nojekyll`。
